# 底部弹层留白验收

日期：2026-10-16；版本：0.7.9（21）。

## 问题与调整

miuix 0.9.4 的 BottomSheetDefaults.insideMargin 默认纵向为 0，原有弹层未额外设置内容末尾间距，导致最后一项或按钮贴底。

设计系统新增 LedgerBottomSheet，继续使用 miuix OverlayBottomSheet，在内容底部统一增加 24dp 留白，并明确保留 defaultWindowInsetsPadding。系统安全区和输入法避让由 miuix 处理，不重复叠加窗口 Insets。

覆盖全部五处调用：编辑页管理分类；分类新增、改名、归档、恢复和操作菜单；资金账户选择与交易时间；账单筛选；删除确认。列表的留白位于滚动容器外，滚动到最后一项时仍保持距离。

qingledger-ui-preview.html 的共用弹层同步为 24px 加 safe-area-inset-bottom，并设置最大高度、溢出滚动和滚动留白。

## 验证

- Debug APK 构建成功，安装到已连接设备 797e378f，启动正常。
- 真机打开编辑页的分类管理，七项分类滚动到底后，新增分类按钮完整显示，下方保留空白。
- 在管理分类上打开新增分类，取消 / 保存按钮下方有留白；聚焦名称弹出键盘后，两按钮仍完整可见，与键盘之间有间距。
- 关闭嵌套面板后打开资金账户选择，最后一张测试银行卡完整显示，底部保留空白。
- 预览 JavaScript 语法检查通过；实际导出 HTML 在浏览器重新加载成功；解码后的同源 QA 页面中，新增分类弹层浅深色计算底部间距均为 24px。
