# 设置页样式验收

日期：2026-10-16；版本：0.7.13（25）。

## 设计基准

以已确认的 qingledger-ui-preview.html 中 settings()、appearance() 和 devtools 弹层为基准。脚本比对 settings() 与 e1dc533 完全一致，保留原三组、四项顺序和文案：

| 分组 | 入口 | 行为 |
| --- | --- | --- |
| 记账设置 | 自动记账 | 显示真实开关状态，进入现有自动记账页 |
| 显示与隐私 | 显示与主题 | 独立二级页，真实保存主题 |
| 显示与隐私 | 隐私与安全 | 底部说明弹层 |
| 高级 | 开发者工具 | 原稿双入口弹层，查看测试器来源说明或诊断 |

没有额外在设置首页增加分类、账户、数据管理或关于项目。分类、账户与关于仍从“我的”页进入。

## 组件与功能

卡片、导航行、按钮、开关、弹层均使用 miuix；主题类型复用 LedgerSegmentedControl。使用现有薄荷绿主题与浅深色，设置与外观标题居中。

显示与主题按原稿保留主题卡、主题色 / 账单显示卡和三个显示选项。跟随系统 / 浅色 / 深色写入原 SettingsRepository，保留保存失败提示。主题色固定薄荷绿；自定义显示开关尚未实现，保持当前真实显示状态，禁用开关调整并通过说明标注。没有把不可保存的选项伪装成已实现。

开发者工具按原稿以底部弹层展示“测试器来源”和“诊断信息”。最小诊断展示实际采集方式、开关、连接状态、所选来源数量及运行错误；不展示页面或通知原文。旧通知回归入口移出自动页，保留在 Debug 工具内，切换前说明会暂停采集。所有弹层复用 24dp 底部留白组件。

## 验证
