# 自动记账页面精简验收

版本：0.7.26（38），2026-10-21。

## 本次修改

- 自动记账首页移除“识别范围”入口及底部入账说明，记录分组仅保留采集记录。
- 采集来源页移除“来源说明”、识别范围、账户关联及底部说明，保留实际来源开关。
- 权限与运行页仅保留后台运行、电池优化、识别通知和实时更新，移除重复的方式及必要权限入口。
- 无障碍授权前移到采集方式选择：未授权时选择无障碍直接打开系统辅助功能设置；当前已选无障碍也可再次点击配置。选择当前方式不重写采集配置；实际切换方式仍沿用暂停采集规则。授权须由用户操作。
- 同步 HTML 设计稿及预览交互提示。Root / Shizuku 仍在方式面板保留，继续标注开发中。

## 验证结果

- `:core:domain:test :app:assembleDebug` 成功；领域模块未变更，复用既有 77 项通过结果。本轮未重跑数据库 instrumentation 测试。
- APK 覆盖安装到已连接真机成功，启动及首页、来源、权限页面布局检查通过。
- 真机选择当前未授权的无障碍方式，成功打开系统辅助功能设置，返回正常；未开启系统权限或触发支付。
- 设计预览 JavaScript 语法、三页移除项断言及原自动记账筛选 / 通知入口 / 二级标题断言通过。文件浏览器自动化受环境限制，本轮未声称浏览器视觉交互验收；以静态检查和真机截图验证布局。
- 正式数据库版本 4，八张业务表逐字段指纹不变；账单 20 条（含已删除）、采集记录 33 条，来源和采集配置未改变。
- 本轮应用进程 AndroidRuntime 错误查询无输出。

未验证：已授权后的选择分支、从旧通知方式实际切换、真实支付采集；本轮未变更这些采集规则。
