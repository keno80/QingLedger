# 轻账 UI 设计方案

日期：2026-10-14。阶段：设计预览，尚未替换 Android 界面。参考：用户提供的记账应用页面合集，以及既有 Compose miuix 技术约束。

## 方向

采用“紧凑账本 + 分组设置”。暖黄橙作为唯一主操作色，支出玫瑰红、收入柔和绿。浅灰底、白色圆角分组，避免每条账单都使用大卡片。界面优先回答金额、商户、账户和交易结果；说明文字缩为一行或移入二级页。

不复制参考应用的账号、会员、订阅、广告和品牌元素。金额及交易在设计稿中均为示例，不代表手机账单。

## 信息架构

底部保留四个入口：账本、统计、自动、我的。记账按钮为账本右下角暖黄色浮动按钮。账户 / 资产放在“我的”快捷入口，不把维护功能都塞进底部栏。

| 层级 | 页面 | 核心信息与操作 |
| --- | --- | --- |
| 主页面 | 账本 | 月份、本月支出 / 收入 / 结余、搜索筛选、按天紧凑账单、记一笔 |
| 主页面 | 统计 | 分类 / 日历切换、分类占比、分类排行、按日流水 |
| 主页面 | 自动 | 一个运行状态卡、总开关、采集方式、权限配置、来源、采集记录 |
| 主页面 | 我的 | 本地账本信息、账户 / 分类 / 自动 / 数据快捷入口、主题、隐私、关于 |
| 账本二级 | 账单详情 | 金额、分类、资金账户、时间、来源、备注、编辑 / 删除与修改历史 |
| 账本二级 | 新增 / 编辑 | 金额、类型、分类网格、账户、商户、时间和备注；底部保存 |
| 我的二级 | 资产与账户 | 账户列表、余额概览、管理账户入口 |
| 我的二级 | 分类管理 | 支出 / 收入切换、分类行、新增、改名、归档和恢复 |
| 我的二级 | 账户管理 | 钱包与不同尾号银行卡分开、活跃 / 归档分组、新增与编辑 |
| 自动二级 | 权限配置 | 必要权限与运行保障分组，每行只显示状态与配置入口 |
| 自动二级 | 采集来源 | 每个来源独立开关、短说明；模拟来源仅在开发者工具中出现 |
| 自动二级 | 采集记录 | 已入账 / 已关联 / 已跳过结果，原因按需展开 |
| 我的二级 | 显示与主题 | 跟随系统 / 浅色 / 深色、主色、紧凑行、账户和来源显示 |
| 我的二级 | 数据管理 | 备份恢复、导入导出、维护；规划功能不可冒充已可用 |

## 视觉规范

- 以 390 dp 宽为设计基准，同时适配 320–430 dp；正常字体内容不横向滚动。
- 页面水平边距 16 dp，分组间距 14–16 dp；卡片圆角 20–24 dp。
- 主页面标题 24 sp，二级标题 17 sp，正文 14 sp，账单标题 13–14 sp，次要信息 11–12 sp。
- 月汇总金额 30–32 sp，单条账单金额 15–17 sp。不要在每个页面重复使用巨型金额。
- 主操作目标至少 44–48 dp；账单行约 64–72 dp。字体放大后允许换行、行高增长，不固定裁切。
- 主色 #FFC244；文字 #25262B；次要文字 #80838E；背景 #F5F5F7；卡片 #FFFFFF。
- 支出 #D85E66，收入 #218B72；同样用“收入 / 支出”和正负号表达含义，不只靠颜色。
- 深色使用独立背景与对比度配色，浅色阴影不过量，不把白色卡片直接反转为纯黑。
- 图标统一线性、约 18–20 dp；分类使用小块低饱和底色，而不是整张卡片着色。

## 关键交互

账单详情 → 编辑保持资金账户与来源。删除使用底部确认弹层，删除后出现限时撤销。筛选用底部弹层，避免独占大段首页高度。记账时类别和账户集中在同一页，保存按钮保持易触达。

自动首页只展示当前是否运行、权限连接、今日入账和最近事件。必要权限、后台设置、来源、方式选择分别进入二级页面 / 底部弹层。无障碍 / Shizuku + ADB / Root 的可用性真实标注；未接入方式禁用开启，不能用设计稿假装已支持。切换方式暂停采集。

每条账单第一行：商户 + 金额；第二行：分类、资金账户；时间、来源标签保持次要。诊断文本、测试器和技术日志移到开发者工具。微信渠道和微信零钱 / 银行卡账户不能合并成一个标签。

## 当前功能与规划功能的区别

账本查询、账单详情 / 编辑、分类 / 账户管理、无障碍状态与来源配置已有业务实现，可以先替换视觉布局。统计分类图 / 日历、账户余额 / 净资产、备份和导入导出仍有业务开发工作；设计稿展示目标结构，当前实现不能启用虚假按钮或虚构余额。

设计预览中所有点击和开关只改变本地演示状态，不写真实账单、不开启设备权限。预览覆盖十四个页面，包含深色、筛选弹层、账户选择、方式选择、导入来源与删除确认。

## 落地顺序

1. 统一 miuix 颜色、圆角、间距、紧凑列表和设置行组件。
2. 优先重做账本、自动、我的，移走长说明和调试信息。
3. 重做详情 / 编辑、分类 / 账户、权限和来源。
4. 统计与资产先保留已有真实数据，再补图表 / 日历 / 余额业务。
5. 规划数据管理入口在功能未完成前标注不可用。

本次只输出 UI 设计，不改 Android 业务与界面源码，不创建新的 APK；下一阶段实际实现后遵循用户约定默认构建安装。

## 预览与验证

[打开完整页面预览](qingledger-ui-preview.html)。预览上方可选择十四个页面以及浅色 / 深色，底部导航和二级入口也可切换；账户选择、筛选、删除确认、转账字段等只在设计预览中交互。

浏览器对 14 页 × 3 个视口（760 / 360 / 320 px）× 2 套主题完成 84 次布局检查，未发现横向溢出或空白页；无脚本运行错误。自动开关、账户选择、转账字段、筛选弹层、统计日历、删除确认与主题切换均操作验证。已视觉检查账本、统计、自动、我的和深色截图；修正浮动记账按钮遮挡最后一条记录的问题。此证据不代替 Android 真机、字体放大与读屏验收。
