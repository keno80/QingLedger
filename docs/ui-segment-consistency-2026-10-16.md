# 分段切换统一与预览同步

日期：2026-10-16。版本：0.7.8（versionCode 20）。

## 变更

- 编辑页和分类管理页原先分别实现切换栏，高度有差异；分类页的轨道又与页面背景同色，视觉上像两套样式。
- 抽取设计系统 LedgerSegmentedControl，两页以及分类新增 / 改名表单复用。继续由 miuix Button 承载点击、禁用及选中语义。
- 统一灰色轨道、白色选中块、40 dp 总高度、4 dp 内边距、14 dp 外圆角、32 dp 按钮高度、10 dp 按钮圆角和 12 sp 文字。轨道使用 miuix secondaryContainer，避免在分类页背景中消失。
- 同步 docs/qingledger-ui-preview.html 的共享 segment 样式，并补齐本轮涉及的编辑页等宽取消 / 保存、去除更多入口、分类卡片列表 / 范围切换及主标签常驻记账按钮。示例数据仅用于设计预览，不写入应用。
- 将“所有 UI 改动同步更新预览文件并验证”的用户要求写入 AGENTS.md，后续继续遵循。

- Debug 构建成功，0.7.8 覆盖安装真机；两页切换栏均查看截图，收支切换正常，当前进程无 AndroidRuntime 错误。截图：debug-artifacts/ui-078-category-tabs.png、ui-078-editor-tabs.png。
