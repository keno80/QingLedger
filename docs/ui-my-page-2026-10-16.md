# 我的页面验收

日期：2026-10-16；版本：0.7.10（22）。

## 页面

- 顶部 miuix 信息卡展示“我的轻账”、本地记账说明和当前“日常账本”。
- “账本管理”卡片包含资金账户与分类管理，两行间使用缩进分割线。
- “应用”卡片包含设置，自动记账入口继续位于设置中。
- 底部轻量展示本地存储说明和实际版本号；不展示虚构的记账笔数、天数或未实现功能入口。

MyScreen 从 SettingsScreen.kt 拆分，导航回调沿用现有实现。卡片使用 miuix Card，导航行使用已依赖的 miuix BasicComponent 自定义内容插槽，复用点击反馈。薄荷绿图标底色、22dp 圆角及浅深色使用现有设计系统。设置页与账户管理页本轮只检查入口，没有重整内部样式。
