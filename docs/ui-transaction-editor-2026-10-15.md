# 新增与编辑账单样式

日期：2026-10-15。版本：0.7.5（versionCode 17）。

本页为 0.7.5 的历史实现记录，布局已由 [0.7.6 设计稿对齐](ui-editor-alignment-2026-10-16.md) 替代；分类恢复为表单内网格，输入信息合并为第二张卡片。

## 页面调整

- 复用 miuix Card、Button、TextField、Icon、OverlayBottomSheet，延续薄荷绿主题。新增与编辑共用 TransactionEditor，候选核对的类型主动选择和自定义保存文案参数继续保留。
- 顶部金额卡包含支出 / 收入 / 转账三项切换及大号金额输入；金额随类型使用支出红、收入绿、转账中性色。
- 商户 / 标题独立输入；分类、账户、时间改为紧凑信息行，点击进入底部面板，避免把全部选项平铺在主表单。转账展示转出和转入账户。
- 分类 / 账户选择使用可滚动列表、主题选中态和“已选择”文字；保留已有归档关联的可见性。不指定分类与实际名为未分类的分类项采用不同文案。
- 交易时间面板保留格式明确的日期 / 时间文本输入。面板暂存修改，完成时检查日期、时间及所在时区的有效性；直接关闭不覆盖表单时间。本轮未新增日历或滚轮选择器。
- 备注独立成卡并展示 500 字计数；底部并排取消和保存，保存为更宽的主题按钮。沿用金额、转账账户、类型主动选择及保存前业务校验。
