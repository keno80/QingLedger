# 轻账 CSV 导入验收

日期：2026-10-16。版本：0.7.20（32）。数据库 schema 仍为 3。

## 入口与交互

我的 → 数据管理 → 导入账单 → 轻账 CSV。保留原数据管理与来源布局，微信、支付宝入口仍说明尚未实现。新增导入二级页沿用 miuix Card、BasicComponent、Button、主题颜色及统一 LedgerBottomSheet，展示文件入口、数量概览、分类与账户匹配、确认操作及可滚动的逐行账单预览。

匹配可选择已有项目、新增同名项目、恢复归档项目，或不设置可选分类 / 账户；转账两端账户必填且不能相同。自动匹配仅用于唯一且使用中的同名项目，归档项目必须显式选择恢复。新增账户初始余额保持未知。匹配选择和预览不保存业务数据，只有点击确认导入才写入。

## 文件与入账规则

- 只支持轻账标准 CSV，UTF-8 严格解码，可含 BOM；最大 16MB / 50000 条非空记录。引号、逗号、字段内换行均支持。表头或 CSV 结构损坏拒绝整个文件；字段错误单独显示行号和原因。
- 收支 / 转账、正数人民币金额、时间偏移与时区一致性、名称及文本长度均校验。显示无效行，允许确认导入其余有效行；待匹配行必须先解决。
- 按原账单 ID 去重，包括已软删除账单；重复项跳过，不覆盖现有内容，也不恢复用户删除的记录。文件内相同 ID 内容冲突时全部判为无效。
- 提交时重新检查 ID 和匹配状态。引用创建 / 恢复、账单和 `IMPORT_CSV` 修改记录在一个 Room 事务内完成，失败整批回滚，重试不会重复写入。保留原 ID、金额、交易时间、时区、商户、备注及来源应用。
- 新版 CSV 为 14 列，末列“文本转义”使用 `v2:` 加实际保护字段列号，确保公式保护单引号可无歧义还原。旧版 13 列仍支持，因无标记而保留其单元格文本中的单引号。CSV 不包含完整账本设置和采集历史，完整恢复仍使用本地备份。
