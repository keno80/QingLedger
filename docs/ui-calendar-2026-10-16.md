# miuix 风格月历与独立日期时间

日期：2026-10-16。源码与已安装版本 0.7.18（30）。对应功能提交：62438b8。

## 用户确认的调整

日期和时间拆为独立入口；日期使用日历选择。无论底层采用哪种实现，整个 App 的视觉必须保持 miuix 风格，该要求已写入 AGENTS.md。

核对 [miuix 官方组件目录](https://compose-miuix-ui.github.io/miuix/components/index)，当前未提供公开的 Calendar / DatePicker。最终实现不引入其他 UI 体系：用现有 miuix IconButton、Button、Text 组成共享月历，使用 LedgerColors 与 MiuixTheme 的薄荷绿、背景和文字颜色；时间继续使用 miuix NumberPicker。没有新增依赖。

## 页面与组件

- 编辑账单主页面将“日期与时间”拆为“日期”和“时间”两行，分别进入独立选择弹层；保存按钮与其他字段沿用已确认设计。
- 日期打开月历，星期一为每周首列；前后箭头逐月切换，点击年月标题进入 miuix 年 / 月定位，再返回月历点击具体日期。
- 月历只绘制实际有效日，选中日使用应用薄荷绿圆角背景与对应文字色，支持浅色 / 深色。浏览月份不会偷偷更改已选日期，底部显示已选值。
- 确定只回填对应日期或时间字段，取消不更改原值；日期变更仍验证与当前时间组合的时区有效性，导出仍验证起止顺序。
- CSV 自定义起止日期复用同一个月历，保留现有导航行与导出入口。时间弹层仅包含时分滚轮及等宽取消 / 确定按钮，不再包含日期 / 时间分段切换。
- 日期可定位 1–9999 年，边界月份禁用越界箭头；月历通过 YearMonth / LocalDate 处理有效日和闰年。全部弹层继续使用共享留白和安全区处理。
