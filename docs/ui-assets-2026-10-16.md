日期：2026-10-16；版本：0.7.14（26）；数据库版本：3。

## 设计与页面

沿用已确认 HTML 的 assets() / accounts()：资产概览展示净资产、总资产、总负债；分组账户列表、管理账户按钮；账户管理分使用中 / 已归档、新增账户及说明。复用 miuix Card、BasicComponent、TextField、Button 与统一留白弹层。

“我的 → 资产与账户”进入真实页面；点击账户进入管理并打开该账户表单。表单同时编辑名称和初始余额，保留归档确认与恢复。新增初始余额的表单及相关说明同步设计预览，预览金额继续明确为示例数据。

## 余额口径

- 初始余额为最早已记录账单之前的余额，不是当前余额；支持 0、负数及两位小数，绝对值不超过 9999999999.99 元。
- 留空表示未知；升级后的旧账户全部为未知，不自动用收支差充当账户余额。账户显示“未设置”；全部未知时概览显示“—”，部分已知时说明已配置比例。
- 账户余额 = 初始余额 + 全部关联收入 − 全部关联支出 + 转入 − 转出，不受月份和分页限制。未指定账户的收支不分摊至任何账户。
- 已删除账单不计入；编辑金额 / 账户、删除、撤销后重新计算。归档账户继续参与资产汇总，避免归档直接抹去资产或负债。
- 总资产累加已知的非负余额，总负债累加已知负余额的绝对值，净资产 = 总资产 − 总负债。未知账户明确排除，因此部分配置时不代表全部实际资产。
- 使用整数分和精确算术；溢出进入读取错误状态，不显示回绕值。账户改名沿用原 API 时保留初始余额，详细表单以事务保存名称和初始余额。
