# 编辑页设计稿对齐

日期：2026-10-16。版本：0.7.6（versionCode 18）。

后续 0.7.7 已将取消 / 保存统一等宽，并重整分类管理页面，见 [分类管理与按钮验收](ui-category-management-2026-10-16.md)。下文保留 0.7.6 的历史记录。

## 对齐内容

0.7.5 将分类移入弹层、把商户和备注拆成独立输入卡，偏离了已确认设计稿。本版恢复设计稿的信息组织，并采用用户最新的按钮要求。

- 顶部居中标题、左侧返回，移除右上角更多操作。
- 第一张卡片集中展示灰底白色选中块的类型切换、无灰底的大号金额，以及四列分类图标网格。类型、分类交互使用 miuix Button / IconButton，输入继续使用 miuix TextField。
- 分类根据真实数据展示，保留已有归档关联；常见分类使用对应线性图标，未匹配分类使用通用图标。网格中的管理入口打开 miuix 分类管理面板，关闭面板保留草稿，不跳离编辑表单。
- 第二张卡片集中展示账户、商户 / 标题、日期时间、备注，采用紧凑信息行及分隔线。商户、备注可直接输入，账户与时间保留选择面板。
- 金额、商户、备注输入取消独立灰底，输入光标保留薄荷绿。原有长度限制、金额与转账校验、时间暂存逻辑继续保留。
- 底部左侧“取消”、右侧更宽的薄荷绿“保存”；两项操作在处理中禁用。新增入口同步使用该布局，候选核对的自定义保存文案继续保留。

## 验证范围

设计对齐阶段已在真机对照查看两张卡片、四列网格、居中标题与金额、白色选中块、信息行和保存操作；分类选中后打开 / 关闭管理面板，选择保留。输入零金额被阻止保存，现有账单未执行有效保存。

最新 Debug 构建成功并覆盖安装，真机截图确认右上角无更多入口、左侧取消 / 右侧保存、标题居中且按钮完整显示；点击取消返回账本列表，未执行有效保存。当前进程无 AndroidRuntime 错误，数据库仍为 13 笔，采集与来源保持关闭。截图：debug-artifacts/ui-076-edit.png、ui-076-cancel-return.png。

本轮未重跑领域测试，未验收深色、大字体、超长自定义分类及有效保存全流程。真机使用实际字体设置与真实账单内容，不以预览中的示例金额、账户或分类替换数据。
