# 分类、账户管理与修改历史验收

日期：2026-10-13。版本：0.3.0 / versionCode 3。范围：补齐 T03 管理入口及修改历史，沿用数据库 schema v1。

## 功能与规则

- 我的 → 分类管理 / 账户管理：新增、改名、归档、恢复。
- 名称去除首尾空格；允许 1–32 个字符，拒绝控制字符。同类分类和账户分别检查重名，包含已归档项并忽略大小写，避免重复建立同一项目。
- 分类收支类型建立后不可切换；转账不建立收支分类。
- 改名保持 ID 和所有账单引用，历史账单显示更新后的名称。
- 归档采用明确确认，不删除账单。新账单选择器排除归档项，编辑原账单可保留已有归档引用；首页筛选仍提供归档项以查询历史。
- 恢复后可再次用于新账单。重启初始化不会覆盖用户名称或归档状态。
- 修改历史按 revision 倒序显示新增、编辑、删除与撤销删除的时间。新编辑记录列出实际改变的金额、类型、商户、分类、账户、时间和备注字段。旧版本的通用 EDIT 记录只显示“编辑账单”，不虚构详细改动。
- 此版本不保存历史字段旧值快照、不提供整笔账单历史版本恢复；10 秒撤销删除保持原规则。

## 技术与数据升级

扩展 LedgerRepository 管理接口和历史 Flow，DAO 新增查询和改名 / 恢复操作。所有管理写入在事务中执行，名称冲突在同一事务检查。复用 transaction_edits.operation 保存字段描述，无 Entity 结构变化。

UI 接入管理入口、输入校验、保存反馈、归档确认、恢复和历史列表。改名与归档点击后滚动到表单 / 确认区域，长名称操作区域使用 FlowRow。APK 通过 install -r 更新，不清除主应用数据。
