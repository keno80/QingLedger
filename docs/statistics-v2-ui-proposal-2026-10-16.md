# 统计页第二版设计提案（待确认）

本轮仅更新 HTML 设计预览，Android 实现仍维持 0.7.22。用户确认此版后再实现，不构建或安装 App。

## 布局

1. 保留统计标题、时段切换、更多入口、悬浮底栏及独立圆形记账按钮。
2. 顶部分段控件从「分类 / 日历」改为「日 / 周 / 年 / 全部」，严格按本轮列出的四种维度，不额外加入月。
3. 首卡展示所选范围的收支概览：环形图区分收入与支出，中心显示结余，右侧分别展示收入与支出金额。
   收支概览标题右侧同一行放置「环形图 / 折线图 / 柱状图」小 Tab，默认环形图；控件总高 30px、按钮高 24px、字号 10px，延续 miuix 分段控件的轨道与选中底色。移除「日统计」及其他重复维度标签。折线图与柱状图同时展示收入、支出，沿用薄荷绿和柔和红；上方紧凑展示收入、支出和结余。
4. 移除「分类排行」标题，在原位置放置「收支排行 / 收入 / 支出」分段控件。
5. 「收支排行」混合展示收入与支出分类，按金额从高到低排列；「收入」「支出」分别过滤排行。下方切换只影响排行，上方概览始终展示完整收支。
6. 排行用薄荷绿正数展示收入、柔和红色负数展示支出；分类占比以同类收支总额为分母，进度条颜色一致。

## 交互与统计口径

- 日、周、年可前后切换；全部隐藏前后切换箭头。周采用周一至周日。
- 切换时间维度保留当前排行类型。
- 切换图表保留时间维度与排行类型。折线图 / 柱状图的日视图按时段、周视图按日、年视图按月、全部视图按年展示；图表分段示例金额合计与收支概览一致。
- 退款按到账时间冲减支出，转账不计收支；实现阶段继续处理负净支出。
- 所有金额均为设计示例，不读取或修改正式账本。

设计待用户确认，暂不将提案作为 Android 的已确认基准。

本轮图表预览的 4 种维度 × 3 种图表 × 3 种排行共 36 个组合通过脚本渲染检查，分段数据合计与概览一致，脚本语法检查通过。浏览器自动读取本地 file 页面受工具策略限制，视觉效果由用户在现有浏览器预览确认；本轮未构建安装 App。
