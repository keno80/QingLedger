# CSV 账单导出

日期：2026-10-16。源码版本：0.7.16（28）。数据库 schema 保持 3。

## 交互

从“我的 → 数据管理 → 导出账单”进入，保持原三组六项数据管理布局。新增底部导出面板使用既有 LedgerBottomSheet、LedgerSegmentedControl 和 miuix TextField / Button，提供本月、全部、自定义；自定义输入开始与结束日期，格式为 yyyy-MM-dd，非法日期及结束早于开始会被拦截。底部左侧取消，右侧选择保存位置，按钮等宽，保留统一留白。

点击选择保存位置后打开系统 CreateDocument（text/csv），默认文件名为带时间戳的“轻账账单-…csv”。保存请求的范围、日期和发起时间随 Activity 状态保存，避免系统选择器期间重建或跨月改变请求含义。取消选择不导出、不修改账单；成功显示导出笔数，失败提示重新导出，不报告成功。

## 数据口径

- 本月按发起导出时刻在账本时区所属的自然月计算。自定义按账本时区的起始日零点到结束日次日零点筛选，包含结束日，正确使用时区规则处理夏令时。
- 导出默认账本的全部收入、支出与转账，排除已软删除账单，按交易时间及 ID 倒序稳定排序。
- 分类、资金账户、转出 / 转入账户名称通过关联查询取得，归档项目仍保留；未指定字段为空。导出不修改业务数据，不受列表 50 笔分页上限影响。
- 在单个数据库事务中读取一致性快照，最多 50000 笔。读取上限加一以发现超量并明确拒绝，要求缩小范围，不静默截断。

## CSV 格式

列顺序：账单ID、交易时间、时区、收支类型、金额（元）、币种、分类、资金账户、转出账户、转入账户、商户、备注、来源应用。

编码为 UTF-8，文件开头 BOM，记录分隔为 CRLF。字段统一双引号包裹，内部双引号翻倍，保留逗号和原始换行。金额由整数分转换为十进制两位小数，不使用浮点数；金额为正数，收支与转账通过类型区分。交易时间包含该笔记录时区的 UTC 偏移，同时单独导出时区 ID。

文本以 =、+、-、@ 开头（包括前导空白后），或首字符为制表 / 回车 / 换行时，前置单引号，避免电子表格将其当作公式。该保护会改变对应单元格的原始文本表示；CSV 以查看分析为用途，不能替代完整备份，也未提供 CSV 恢复或导入能力。
