# 日期时间组件调整

日期：2026-10-16。源码与已安装版本：0.7.17（29）。

## 调整原因与组件

用户指出 CSV 自定义日期不应要求手输。将可选择的日期 / 时间改为组件交互，优先复用已依赖的 miuix 0.9.4 NumberPicker，不增加其他 UI 库。

组件 API 已核对 [官方文档](https://compose-miuix-ui.github.io/miuix/components/numberpicker) 与 [v0.9.4 源码](https://github.com/compose-miuix-ui/miuix/blob/v0.9.4/miuix-ui/src/commonMain/kotlin/top/yukonga/miuix/kmp/basic/NumberPicker.kt)。设计系统新增 LedgerDatePicker / LedgerTimePicker，直接使用 miuix 的滚动、吸附、触感与主题颜色。

## 页面行为

- CSV 自定义日期：开始日期 / 结束日期为导航行，点击在同一底部弹层内进入年月日选择，取消返回并保留原值，确定后更新对应日期。底层仍校验起止顺序，用户无法通过选择器产生 2 月 30 日。
- 编辑账单：日期时间弹层显示当前草稿，提供日期 / 时间分段切换；分别选择年月日或时分。确定后写回编辑草稿，取消不更改原值。保留不存在的本地时间校验。
- 年范围 1–9999、月 1–12、日按当前年月计算；小时 0–23、分钟 0–59。切换年月时 LocalDate 自动将月末收敛至有效日；天数范围变化时重建日滚轮，取消旧范围的惯性状态。
- 确认与取消按钮等宽，弹层继续复用 24dp 底部留白与系统安全区。原数据管理三组六项及账单编辑主布局保持不变。
