# 账单详情样式落地

日期：2026-10-15。版本：0.7.4（versionCode 16）。

## 页面与交互

- 延续薄荷绿主题，优先使用 miuix Card、Text、Icon、Button、OverlayBottomSheet，未引入 Material 替代组件。
- 顶部卡片集中展示图标、商户 / 标题、收支类型、大号金额与记账方式。支出红色负号、收入绿色正号；转账使用中性金额。
- 交易信息卡展示分类、资金账户、时间和来源；转账改为转出 / 转入账户，不展示收支分类。备注独立成卡，完整换行显示。
- 修改记录默认收起，点击卡片展开 / 收起，保留真实条数、操作说明及秒级时间，按时间倒序排列。
- 删除和编辑并排，编辑使用主题主按钮。删除打开 miuix 底部确认面板，显示类型、金额和原有 10 秒撤销说明；处理中禁用重复操作。移除重复的“返回账单”按钮，保留页面顶部返回和系统返回。
- 沿用已有编辑、删除及撤销业务，本轮没有更改存储逻辑和账单数据。新增 / 编辑表单样式不属于本轮范围。
