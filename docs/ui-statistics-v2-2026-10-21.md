# 统计页第二版验收

版本：0.7.23（35）。用户于 2026-10-21 确认按此前 HTML 设计开始实现。设计基准为 `qingledger-ui-preview.html`，详细设计见 `statistics-v2-ui-proposal-2026-10-16.md`。

## 已实现

- 顶部分段：日 / 周 / 年 / 全部，日、周、年支持前后切换，全部隐藏箭头。筛选由独立 ViewModel 管理，不改变账本月份或搜索。
- 收支概览标题右侧使用纯图标小 Tab：环形图 / 折线图 / 柱状图。复用 miuix 按钮、主题轨道与选中底色，图标具有无障碍名称；不显示日统计标签。
- 环形图展示收入与净支出构成，中心显示结余；折线与柱状图同时显示收入、支出，分别按日内 4 小时时段、周内日期、年内月份、全部年份分桶。
- 收支排行 / 收入 / 支出只筛选下方分类排行。收支混排按净额绝对值降序，各分类占比按同类正向净额计算；负支出分类标注退款净额。
- 点击排行打开分类流水面板，可进入账单详情；返回保留时间、图表及排行状态。长分类排行分批展示，分类流水使用懒加载列表，悬浮导航和记账按钮保留。
- 正式数据读取不带 50 / 10000 条分页限制，只排除删除记录并按半开时间范围筛选；聚合在后台线程执行。移除账本为旧统计页额外读取整月流水的开销。

## 统计边界

使用账本时区，日界线从当地零点到次日零点；自然周为周一至周日，自然年为 1 月 1 日至次年 1 月 1 日。夏令时日长度不固定为 24 小时。

退款在到账时段冲减支出，不计收入。趋势图保留负值并支持零轴以下展示；净支出为负时，环形图仅绘制正向收支并显示说明，金额及结余保留真实值。空时段显示零额和空排行，全部时间只有一年时折线图显示一个真实数据点，不编造其他年份。
