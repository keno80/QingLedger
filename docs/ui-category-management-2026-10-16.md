# 分类管理页面与等宽操作按钮

日期：2026-10-16。版本：0.7.7（versionCode 19）。

## 页面调整

- 新增 / 编辑表单底部左侧取消、右侧保存，均使用 weight 1、48 dp 最小高度，间距 12 dp。新增时金额占位文字也保持居中大号样式。
- 分类管理保留居中标题与返回，使用支出 / 收入切换、使用中数量与归档范围切换、紧凑分类卡片和新增按钮，不再常驻大段管理说明与新增表单。
- 分类行展示共享的分类图标、名称及操作入口；点击整行或右侧按钮进入 miuix 操作面板。
- 新增与改名使用 miuix 底部表单，保留 1–32 字名称校验。新增可选择收支类型，改名时类型不可更改；取消 / 保存等宽。
- 归档前显示确认面板，说明已有账单不受影响；已归档分类可恢复使用，继续调用原有仓库逻辑。
- 我的 / 设置入口与编辑页中的分类管理面板复用同一分类界面，账户管理保持原实现。分类图标映射抽到设计系统，避免管理与编辑页各自维护。
- 基于当前真实的扁平分类模型展示，没有添加无业务支持的子分类展开箭头或排序按钮。
