# 轻账 CSV 导入实施计划

目标：接入现有“导入账单 → 轻账 CSV”，实现文件选择、预览、分类 / 账户匹配、重复检查和确认导入。保持 miuix 风格，不改动微信 / 支付宝导入入口的实现状态。

规则：支持轻账导出列，UTF-8 严格解码、最大 16MB / 50000 行；按原账单 ID 去重，包括已删除账单。错误行列出原因，可导入有效行；待匹配项必须先解决。新建账户初始余额未知。确认时重新校验，事务内完成引用创建 / 恢复、账单与修改记录写入，失败整体回滚。预览与取消不写业务数据。

旧 13 列导出没有记录公式防护是否插入过单引号，无法无歧义还原；兼容读取但保留原文本。新版导出增加“文本转义”列标记实际防护字段，导入能精确还原文字，同时保留本来就以单引号开头的原文。

- [x] domain：先写解析测试，覆盖引号 / 换行、编码与大小、金额 / 时区、转账及新版文本往返。
- [x] data：实现预览、映射、去重与事务提交；编写独立数据库测试覆盖并发变更、重复、软删除和中途失败回滚。
- [x] app：新增导入 ViewModel 和二级预览页面，现有来源弹层接入系统文件选择与匹配操作。
- [x] 同步 HTML 预览、导出说明、开发进度与验收文档。
- [x] 构建安装，运行单元与数据库测试，真机验证重复文件、预览 / 匹配 / 取消及账本不变。
- [x] 暂存全部变更，中文 Conventional Commit，直接推送。
