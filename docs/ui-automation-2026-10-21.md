# 自动记账页面设计落地验收

版本：0.7.25（37）。按 `qingledger-ui-preview.html` 的自动记账、权限、来源与记录设计实现，使用 miuix Card、BasicComponent、Switch、按钮及统一底部面板。

## 界面与导航

- 首页：运行状态卡、今日自动记账、最近识别；采集方式 / 权限与运行 / 采集来源；采集记录 / 识别范围。
- 方式面板保留无障碍、Shizuku + ADB、Root。后两者显示开发中，点击仅说明尚未接入，不执行命令、不切换运行方式。切换到已实现的无障碍方式仍沿用原来暂停采集的规则。
- 权限与运行页展示访问权限、监听连接、支付来源、后台 / 电池配置、识别通知及实时更新，支持进入系统设置；从系统返回刷新实际状态，不自动授予权限。
- 来源页使用独立开关；未安装应用禁用切换，Debug 模拟来源明确标注，不自动开启微信或支付宝。
- 记录页按日期分组，共用分段控件筛选全部 / 已入账 / 已跳过；先显示结果，再通过面板查看原因及关联账单。进入账单详情再返回会保留记录筛选。旧版待确认事件保留独立入口。
- 已处理记录隐藏操作移至开发者工具诊断面板，避免首页出现维护操作；仍保留去重标记和正式账单。

## 真实数据

今日数量使用独立完整查询，按账本时区的当日半开区间统计 `AUTO_POSTED` 的不同交易 ID；不受可见列表 200 条上限或隐藏状态影响，也不把人工确认、同笔关联算作新的自动入账。

最近识别同样读取完整记录，商户与账户名称连接实际账单；没有商户时显示来源与结果，不编造商户。记录列表仍展示最近 200 条未隐藏记录，筛选范围有明确说明。数据读取失败时今日数量显示未知值，不伪造 0。
