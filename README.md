# 轻账 QingLedger

本地优先的 Android 自动记账应用，使用 Compose miuix，视觉层次参考 HyperCeiler。

## 开发环境

- JDK 17；Android SDK 37；最低 Android 11 (API 30)。
- AGP 9.4.1、Gradle 9.7.1、Kotlin 2.4.20。
- Compose Multiplatform 1.12.0、Compose miuix 0.9.4；仅交付 Android。
- Android Studio 打开此目录，配置本机 SDK。local.properties 不进入版本控制。
- 用户于 2026-10-14 更新约定：完成功能后默认构建并安装到已连接真机，检查基本启动与功能入口。

依赖组合与状态详见 [兼容说明](docs/compatibility.md)，进度和人工验收清单详见 [开发进度](docs/progress.md)。

产品与开发规格见 [产品需求文档](docs/产品需求文档.md)、[开发文档](docs/开发文档.md)。页面重整方案见 [UI 设计规范](docs/ui-design-2026-10-14.md)，设计预览尚未替换 Android 界面。下一阶段验证真实来源的脱敏通知模板与版本覆盖；Root / Shizuku 保持独立验证，不直接读取支付应用私有数据。
